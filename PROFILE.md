## APIs

- **RubiConnect Messaging Platform** — REST API for sending messages, managing campaigns, RCS capability checks, and webhook callbacks. Auth via API key (X-API-Key) or Bearer token. (`https://console.rubiconnect.com/api/v1`)
- **RubiConnect MCP Server** — Hosted MCP server exposing 18 tools for messaging, templates, campaigns, agents, analytics, and media. Auth via OAuth 2.0/PKCE or API key. (`https://console.rubiconnect.com/api/mcp`)
